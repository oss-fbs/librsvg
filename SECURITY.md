# Security Policy

## Supported Versions

| Version   | Supported          |
|-----------|--------------------|
| 2.63.x    | :white_check_mark: |
| 2.62.6+   | :white_check_mark: |
| < 2.62.6  | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub’s **Private vulnerability reporting** feature (available on the Security tab of this repository).

Do **not** open a public issue for security problems.

If private vulnerability reporting is unavailable, contact the maintainer at **oss@familybusinesssoftware.com**.

When reporting, include:

- A description of the issue
- Steps to reproduce
- Affected versions
- Any suggested fix or mitigation (optional)

We will acknowledge receipt, investigate, and coordinate a fix and disclosure timeline with you.

## Preferred Versions

Due to previously disclosed security issues, users are strongly advised to use **2.62.6** or any later release. Earlier versions in the 2.62 series should be considered vulnerable and replaced.
